# PedidoApp

PedidoApp es una aplicación para Android para digitalizar los pedidos y facilitar su impresión en forma de ticket.

En esta primera etapa, está hardcodeada para cumplir los requisitos de La Cocina de So.

**Próximamente:** Posibilidad de gestionar un Menú!

## Tecnologías

- .NET MAUI
- C#
